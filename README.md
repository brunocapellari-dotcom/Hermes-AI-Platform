# Hermes AI Platform

Canonical shared AI platform for the ecosystem.

Hermes is the intelligence and orchestration layer. It does not replace the AI-Holding Control Plane, the Second Brain knowledge system, Research AI, or project-specific domain logic.

## Non-negotiable principles

- Final architecture first; no disposable prototype strategy.
- Evidence-based model/tool routing.
- Least privilege and external policy enforcement.
- Durable mission state and idempotent execution.
- Selective context retrieval; never copy the full knowledge vault into model context.
- External content is untrusted by default.
- Cognitive capability does not grant authority.
- Every production-relevant action is observable and auditable.
- The AI-Holding remains the portfolio/governance authority.
- Zero incremental vendor spend is the default go-live target; local execution is the production baseline and paid cloud infrastructure is optional post-go-live.

## Current state

Repository bootstrap only. Production readiness is determined exclusively by acceptance tests, Golden Tasks, Security Test Lab, and full E2E results.
